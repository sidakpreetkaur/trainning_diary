📘 Training Diary — Data Analytics & Machine Learning

This repository contains my 4-week training journey in Data Analytics and Machine Learning. During the training, I learned the complete data analytics workflow, including Python programming, data cleaning, exploratory data analysis, visualization, feature engineering, dimensionality reduction, anomaly detection, supervised learning, regression, feature selection, and hyperparameter tuning.

As a practical project, I developed a Superstore Sales & Profit Analyzer Dashboard to analyze sales, profit, discounts, shipping performance, and other business insights using Python, Pandas, NumPy, Matplotlib, Seaborn, Machine Learning, and Streamlit.
